# Notifique SDK

**[English](#english)** · **[Português](#português)**

Docs: [docs.notifique.dev](https://docs.notifique.dev)

---

## English

Official **server-side** SDKs for [Notifique](https://notifique.dev). Pick your language, run the install command, then open that package’s README for examples.

Device push (Web, React Native, Flutter, etc.) lives in [notifique-push-sdks](https://github.com/notifique-dev/notifique-push-sdks) — not in this repo.

### Install

| Language | Install | Package README |
|----------|---------|----------------|
| Node.js / TypeScript | `npm install @notifique/sdk-node` | [sdk-node](packages/sdk-node/README.md) |
| Python | `pip install notifique-sdk` | [sdk-python](packages/sdk-python/README.md) |
| Go | `go get github.com/notifique-dev/notifique-sdk/packages/sdk-go@v0.2.1` | [sdk-go](packages/sdk-go/README.md) |
| Java (Maven) | `dev.notifique:notifique-sdk:0.2.1` | [sdk-java](packages/sdk-java/README.md) |
| Java (Gradle) | `implementation 'dev.notifique:notifique-sdk:0.2.1'` | [sdk-java](packages/sdk-java/README.md) |
| .NET | `dotnet add package Notifique` | [sdk-dotnet](packages/sdk-dotnet/README.md) |
| PHP | `composer require notifique/notifique-sdk-php` | [sdk-php](packages/sdk-php/README.md) |
| Elixir | `{:notifique, "~> 0.2.1"}` in `mix.exs` | [sdk-elixir](packages/sdk-elixir/README.md) |

### Java — Maven

```xml
<dependency>
    <groupId>dev.notifique</groupId>
    <artifactId>notifique-sdk</artifactId>
    <version>0.2.1</version>
</dependency>
```

### Java — Gradle

```gradle
implementation 'dev.notifique:notifique-sdk:0.2.1'
```

### Elixir

```elixir
{:notifique, "~> 0.2.1"}
```

Then `mix deps.get`.
