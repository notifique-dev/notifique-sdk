# @notifique/core

**[English](#english)** · **[Português](#português)**

Shared TypeScript types for Notifique SDKs (v0.2.1). Most apps should install `@notifique/sdk-node` instead.

---

## English

```bash
npm install @notifique/core
```

```typescript
import type { SendPushParams, SmsSendParams, OpResponse } from '@notifique/core';
```

Usually installed automatically as a dependency of `@notifique/sdk-node`.

---

## Português
